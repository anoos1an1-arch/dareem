# ذادريـم

موقع روابط شخصي بتصميم 3D خفيف، يعمل على GitHub Pages، مع Supabase للمصادقة وقاعدة البيانات.

## الملفات

- `index.html` — صفحة الزائر.
- `admin.html` — لوحة الإدارة.
- `app.js` — قراءة الروابط وعرض الخلفية المتحركة.
- `admin.js` — تسجيل الدخول وإضافة/تعديل/حذف الروابط.
- `styles.css` — التصميم.
- `config.js` — بيانات Supabase العامة.
- `supabase.sql` — الجداول وسياسات RLS.

## الإعداد

1. أنشئ مشروعًا في Supabase.
2. من Authentication أنشئ مستخدمًا بالبريد وكلمة المرور.
3. افتح SQL Editor وشغّل `supabase.sql`.
4. خذ UUID للمستخدم من Authentication > Users، ثم نفّذ:
   `insert into public.admins (user_id) values ('UUID');`
5. ضع Project URL وPublishable/Anon Key في `config.js`.
6. ارفع الملفات إلى مستودع GitHub.
7. من Settings > Pages فعّل النشر من الفرع الرئيسي ومجلد `/root`.
8. صفحة الإدارة ستكون `/admin.html`.

## الأمان

المفتاح الموجود في `config.js` يجب أن يكون anon/publishable فقط. لا تضع `service_role` في ملفات GitHub.

الحماية الفعلية للتعديل موجودة في RLS داخل Supabase؛ إخفاء لوحة الإدارة وحده ليس حماية.
الزائر يستطيع قراءة الروابط فقط. حساب موجود في جدول `admins` هو الذي يستطيع الإضافة والتعديل والحذف.

## التحقق

بعد الإعداد:
- افتح الموقع كزائر وتأكد أن الروابط تُقرأ.
- افتح `/admin.html` وسجّل الدخول بالحساب المصرّح.
- جرّب إضافة رابط ثم عد للصفحة الرئيسية.
- جرّب حسابًا آخر؛ يجب أن يفشل في عمليات الكتابة بسبب RLS.
